<!-- Featured Projects Section -->
<h3 align="left">📂 Featured Systems Projects:</h3>

* 🚀 **[ShipDeck](https://github.com/ultimateprodigy/shipdeck):** A self-hosted Developer PaaS (like Heroku) written in TypeScript and Java. Automates Git-to-deploy pipelines, handles dynamic TCP reverse proxying, atomic blue-green container swaps via Docker socket interactions, and collects cgroups system telemetry.
* 🔥 **[VeloDB](https://github.com/ultimateprodigy/velodb):** An in-memory vector similarity database written in Java and TypeScript. Achieves sub-10ms search query speeds over 500K+ vectors by bypassing JVM Garbage Collection pauses entirely using `sun.misc.Unsafe` off-heap memory, accelerated by hardware-level SIMD math via the Java Vector API.
* 🌊 **[Hydra](https://github.com/ultimateprodigy/hydra):** A high-throughput log aggregator routing 50K+ requests/sec. Features edge token-bucket rate limiters in TypeScript, passing log streams to a lock-free circular Ring Buffer in Java to execute zero-allocation asynchronous batch writes.
* ⏰ **[Chronos](https://github.com/ultimateprodigy/chronos):** A fault-tolerant distributed cron task scheduler. Uses Hashed Wheel Timers in Java to schedule millions of tasks in $O(1)$ constant time, dispatching execution workloads to TypeScript worker nodes over custom keep-alive TCP socket channels.
